# Example reference file

A reference file holds facts that are too long or too exact for `SKILL.md`: field tables,
regexes, literal templates, command catalogs. `SKILL.md` stays short and points here by
relative path, with a note on when to read it, so the file is loaded only when a step needs it.

Keep one topic per file and name the file after the topic. Give a file longer than about
300 lines a table of contents at the top.
